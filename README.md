# NewsHub

A news website built on my own as a front-end practice project during the DEPI Front-End track.

Status: in progress

## Live demo
https://yousaprafaat24-del.github.io/NewsHub/

## Features
- Home page with 4 news sections: Sports, Entertainment, Health and Business
- Weather section
- Currency rates (separate Currency.html page)
- Navigation bar built with Bootstrap

## Technologies
- HTML
- CSS
- Bootstrap
- JavaScript

## Project structure
NewsHub/
├── index.html      # home page
├── Currency.html   # currency rates page
├── app.css         # custom styles
└── Jscode/         # JavaScript files
## How to run
1. Download or clone the repository.
2. Open index.html in any browser.
